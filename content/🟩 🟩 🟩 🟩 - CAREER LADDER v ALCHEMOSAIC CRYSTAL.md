If a single raw log file in [C]_capture is modified, the downstream hashes break instantly. This guarantees that the **Expression** layer is mathematically tethered to the original **Capture** layer.

## 3. NATIVE VERIFICATION IMPLEMENTATION BLOCK

To securely verify this manifest local-first, the Rust backend needs to confirm two rules:

1. **The physical file content matches the manifest hashes** (Data Integrity Check).
2. **The signatures are mathematically valid over the data payload** (Cryptographic Trust Check).

Here is how you structure that engine logic:

use sha2::{Digest, Sha256};

use std::io::{Read, Result as IoResult};

impl SyncZineManifest {

/// Computes the deterministic hash of the entire CODE lifecycle block.

/// This is the payload that the Learner, Sage, and Warden cryptographically sign.

pub fn compute_code_payload_hash(&self) -> Result<String, serde_json::Error> {

// Canonicalize by serializing the structural code container specifically.

// For production, look into deterministic JSON serialization (RFC 8785)

let serialized_target = serde_json::to_string(&self.code_v_structure)?;

let mut hasher = Sha256::new();

hasher.update(serialized_target.as_bytes());

let result = hasher.finalize();

Ok(format!("sha256:{:x}", result))

}

/// Verifies that an extracted file payload matches its recorded structural hash.

pub fn verify_file_integrity<R: Read>(&self, mut reader: R, expected_hash: &str) -> IoResult<bool> {

let mut hasher = Sha256::new();

let mut buffer = [0; 4096];

loop {

let count = reader.read(&mut buffer)?;

if count == 0 { break; }

hasher.update(&buffer[..count]);

}

let calculated = format!("sha256:{:x}", hasher.finalize());

Ok(calculated == expected_hash)

}

}
